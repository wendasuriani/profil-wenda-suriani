# Profil Profesional - Wenda Suriani

## Deskripsi
Website ini merupakan halaman profil statis yang dibuat sebagai bagian dari **Tugas Pemantapan 1** pada mata kuliah Pemrograman Web.

Halaman profil berisi informasi mengenai profil, pendidikan, keterampilan, minat dan hobi, serta informasi kontak.

## Teknologi yang Digunakan
- HTML5
- CSS3
- Visual Studio Code
- Git dan GitHub

## Struktur File
```text
profil/
├── index.html
├── style.css
└── README.md
```

## Fitur Halaman
- Profil profesional
- Informasi pendidikan
- Daftar keterampilan
- Minat dan hobi
- Informasi kontak
- Navigasi antarbagian halaman

## Cara Menjalankan
1. Buka folder project di Visual Studio Code.
2. Buka file `index.html`.
3. Jalankan file tersebut menggunakan browser.
4. Halaman profil akan ditampilkan pada browser.

## Penggunaan AI
AI digunakan sebagai bantuan dalam memahami struktur HTML5 semantik, penyusunan CSS, serta penggunaan Git dan GitHub dalam pengelolaan repository.

Kode dan isi halaman tetap diperiksa, dipahami, dan disesuaikan oleh mahasiswa dengan kebutuhan tugas.

## Repository
Project ini dikelola menggunakan Git dan GitHub sebagai bagian dari penerapan version control.
